## Data safety
- Does your app collect or share user data? **Yes, collects.** Shared with third parties? **No**
  (Supabase/Cloudflare are service providers, which Play doesn't count as sharing.)
- Is all data encrypted in transit? **Yes**
- Can users request data deletion? **Yes.** In-app (You → Settings → Delete account)
  and URL: https://songsnap.online/privacy#delete

| Data type | Collected | Shared | Optional? | Purposes |
|---|---|---|---|---|
| Personal info → Name | Yes | No | Optional (guests have none) | App functionality, Account management |
| Personal info → Email address | Yes | No | Optional (guests have none) | Account management |
| Personal info → User IDs | Yes | No | Required | App functionality, Account management |
| App activity → App interactions (reactions, follows) | Yes | No | Required | App functionality |
| App activity → Other user-generated content (posts, comments) | Yes | No | Optional | App functionality |

Not collected: location, contacts, photos/videos, audio, files, calendar, messages, health,
financial info, web browsing, device or other IDs, app info & performance (no crash/analytics SDKs).

## Account deletion (Play policy)
